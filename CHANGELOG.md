## 12.4.0

### Added

- Throttler: optional `anonymousIpRateLimit` / `anonymousIpRateLimitTTL`, a second per-IP bucket that only counts unauthenticated requests (and requests rejected by a proxy middleware). It runs alongside `globalIpRateLimit`, which still counts all traffic. Together they give a high all-traffic ceiling for shared NAT addresses and a tight limit for anonymous traffic.
- Throttler: `keyResolver` may return `{ key, authenticated }` to mark a request as authenticated. Returning a string still works and is treated as anonymous.
- Throttler: `ipv6Subnet` option (default `64`) and the normalised client address passed to `keyResolver` as `ip`.
- `ThrottlerService.checkAnonymousIpRequest`, used by the proxy for requests the middlewares reject.

### Changed

- IP-based rate-limit keys use a normalised client address: IPv4-mapped IPv6 addresses (`::ffff:1.2.3.4`) become plain IPv4, and IPv6 addresses are masked to their /64 prefix. IPv6 clients that previously had one bucket per address now share one per /64; existing IPv6 counters start fresh after the upgrade. Set `ipv6Subnet: 128` for per-address buckets.
